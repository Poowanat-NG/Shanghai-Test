# Trip map website

This folder is the website repository. Upload the files **inside this folder** to the root of a GitHub repository.

Before deployment, edit `config.js` and replace the placeholder with your own deployed Google Apps Script Web App URL. Do not put an OpenAI API key, Google password, passcode, or private Sheet ID in this folder.

For a local preview, run this command from this folder:

```text
python3 -m http.server 8000
```

Then open `http://localhost:8000`.
